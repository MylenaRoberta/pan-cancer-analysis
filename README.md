# A layered quadripartite network architecture for pathway-contextualized microRNA regulation analysis

## Abstract

A challenge in studying microRNA (miR) regulation is determining how miRs relate to biological pathways. Network-based approaches commonly overlook the internal structure of pathways, representing them as monolithic entities. We propose a layered quadripartite network (LQN) architecture comprising miRs, messenger RNAs (mRNAs), pathway locations, and pathways to enable pathway-contextualized analysis of miR regulation. The proposed architecture extends our Transparent Reproducible Pipeline (TRP) for modeling miR networks in cancer. Using breast cancer data from The Cancer Genome Atlas (TCGA), we show that the pathway location layer reveals regulatory information that is not captured by mRNA--pathway associations alone.

## Installation Instructions

The following instructions describe how to set up the project environment on Linux distributions based on Ubuntu or Debian.

### 1. System Requirements

- Python 3.11–3.13
- R 4.1+
- Git

Install the required system dependencies:

```bash
sudo apt update
sudo apt install -y git python3 python3-pip python3-venv python3-dev \
    r-base r-base-dev build-essential libssl-dev \
    libcurl4-openssl-dev libxml2-dev
```

**Note:** Ensure that the Python interpreter used to create the virtual environment meets the version requirement above. Depending on the Linux distribution, an additional Python installation may be necessary.

### 2. Clone the Repository

Clone the repository and navigate to its root directory:

```bash
git clone https://github.com/LIS-Unicamp/pan-cancer-analysis.git
cd pan-cancer-analysis
```

To reproduce a specific release, check out its corresponding Git tag.

### 3. Python Environment Setup

Create and activate a Python virtual environment using a compatible Python interpreter:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Upgrade `pip` and install the Python dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. R Dependencies

The pipeline uses R packages for selected analytical procedures, accessed from Python through `rpy2`.

Start an R session:

```bash
R
```

Install the required packages:

```r
# Install BiocManager if necessary
if (!requireNamespace("BiocManager", quietly = TRUE)) {
    install.packages("BiocManager")
}

# Install edgeR from Bioconductor
BiocManager::install("edgeR")

# Install additional R packages
install.packages(c("ggplot2", "statmod"))
```

Exit the R session with `q()`.

## Pipeline Execution

The analysis is organized into Jupyter notebooks, with shared configuration defined in `config.py`.

Open the notebooks in a Jupyter-compatible environment, select the configured Python virtual environment, and execute the stages in the order documented in [notebooks/README.md](notebooks/README.md).

Some pipeline stages retrieve data from external sources or generate artifacts that are not tracked by Git. Consult [data/README.md](data/README.md) for details about the data artifacts and their organization.
