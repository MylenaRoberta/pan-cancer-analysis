# Examples of Data Artifacts

This directory contains small sample files illustrating the data artifacts used and generated by the **Transparent Reproducible Pipeline (TRP)**.

## Included Files

- `biopax-pathway-flattened-network-edges-file.csv`: Example of BioPAX flattened pathway network edges.
- `biopax-pathway-flattened-network-nodes-file.csv`: Example of BioPAX flattened pathway network nodes.
- `biopax-pathway-projected-network-edges-file.csv`: Example of BioPAX projected pathway network edges.
- `biopax-pathway-projected-network-nodes-file.csv`: Example of BioPAX projected pathway network nodes.
- `gprofiler-origin-pathway-enrichment-file.csv`: Example of original g:Profiler pathway enrichment results.
- `gprofiler-processed-pathway-enrichment-file.csv`: Example of processed g:Profiler pathway enrichment results.
- `mirna-seq-origin-file.txt`: Example of original TCGA miRNA-Seq expression data.
- `mirna-seq-processed-file.txt`: Example of processed TCGA miRNA-Seq expression data.
- `mirwalk-origin-file.csv`: Example of original miRWalk target prediction data.
- `mirwalk-processed-file.csv`: Example of processed miRWalk target prediction data.
- `rna-seq-origin-file.txt`: Example of original TCGA RNA-Seq expression data.
- `rna-seq-processed-file.txt`: Example of processed TCGA RNA-Seq expression data.

## Purpose

These files are provided for demonstration, testing, and documentation purposes only. Full datasets are not included in the repository due to their size and must be obtained or generated separately.

For detailed descriptions of the artifacts, including their schemas, identifiers, and provenance relationships, refer to the [Data Artifact Documentation](../README.md).
